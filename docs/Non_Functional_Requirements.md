# Non-Functional Requirements

## Performance

- The system should respond quickly to user requests.
- Support multiple users simultaneously.

## Security

- JWT-based authentication.
- Password encryption.
- Role-based authorization.
- Secure file upload.

## Reliability

- Maintain accurate warranty records.
- Prevent data loss through database integrity.

## Scalability

- Support increasing users and warranty claims.
- Easy to extend with new modules.

## Usability

- Simple and user-friendly interface.
- Responsive design for different screen sizes.

## Maintainability

- Modular code structure.
- Proper documentation.
- Version control using Git.

## Availability

- System should be available whenever users need access.

## Compatibility

- Compatible with modern web browsers.
- Works on desktop and mobile devices.
